# Таймер обратного отсчёта

Простое React-приложение для отсчёта времени с возможностью установки таймера в минутах и секундах.

## Функциональность

- Установка времени в минутах и секундах
- Запуск и пауза таймера
- Сброс таймера
- Адаптивный дизайн
- Современный интерфейс
